# MyCoco — Phase 1 Data & Monetization Strategy

## Objective
Build a dense local childcare marketplace first, while every qualified parent search creates structured, privacy-conscious demand intelligence that can later power provider leads, subscriptions, sponsored placement and employer products.

## Data captured today
- City / postal code
- Child age range
- Childcare type preference
- Desired start date
- Locale
- Acquisition source / UTM source, medium and campaign when available
- Referrer
- Timestamp and demand status in the database

## North-star dataset
For every active need, MyCoco should eventually answer:
- Where is demand?
- For which child age?
- For which childcare type?
- When is care needed?
- Which acquisition channel creates the best demand?
- Which providers receive relevant demand?
- Which areas/categories have unmet demand?

## Monetization path
1. Free parent search creates demand.
2. Aggregate demand by geography, age, type and timing.
3. Recruit providers with proof of local demand.
4. Sell qualified leads, provider subscriptions and sponsored visibility only after liquidity exists.
5. Later add booking/transaction revenue and employer family-care products.

## Rule
Do not sell raw personal data. Monetize access to qualified demand, workflow tools, aggregated market intelligence and transactions.
